# Bienestar Menopáusico

Crea una aplicación web responsive llamada "Menopausia Sin Hinchazón".



Objetivo:

Ayudar a mujeres en perimenopausia y menopausia que sufren inflamación abdominal, fatiga y despertares nocturnos.



La aplicación debe estar completamente en español.



Funciones:



1. Inicio

   Registro diario de:



- Inflamación abdominal (1 a 10)

- Energía (1 a 10)

- Calidad del sueño (1 a 10)

- ¿Te despertaste entre las 2 y las 4 AM? (Sí/No)



Botón Guardar.



2. Historial

   Mostrar gráficos de:



- Inflamación abdominal

- Energía

- Sueño

- Despertares nocturnos



Filtros:



- Últimos 7 días

- Últimos 30 días

- Últimos 90 días



3. Asistente IA

   Permitir preguntas sobre:



- Inflamación abdominal

- Fatiga

- Sueño

- Menopausia



La IA debe aclarar que no reemplaza el consejo médico profesional.



4. Próxima Consulta

   Generar automáticamente:



- Resumen de síntomas

- Evolución de los últimos 30 días

- Preguntas sugeridas para el médico



5. Biblioteca

   Categorías:



- Inflamación abdominal

- Fatiga

- Sueño

- Despertares nocturnos

- Menopausia

- Alimentación

- Estrés



Diseño:



- Moderno

- Elegante

- Fácil de usar desde celular

- Colores suaves

- Menú inferior con iconos



Requisitos:



- Registro de usuarios

- Inicio de sesión

- Diseño optimizado para móviles

- Preparada para agregar suscripción premium en el futuro
